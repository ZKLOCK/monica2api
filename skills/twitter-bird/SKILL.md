# Twitter Bird Skill - 社交媒体自动化

Twitter/X平台自动化工具。

## 功能
- 自动发帖和转推
- 内容监控和分析
- 粉丝互动管理
- 趋势话题追踪

## 使用方法
```bash
# 发送推文
openclaw twitter post --text "Hello Twitter!"

# 监控话题
openclaw twitter monitor --hashtag "AI"

# 分析账号
openclaw twitter analyze --username "openai"

# 自动互动
openclaw twitter engage --keyword "机器学习"
```

## 注意事项
- 需要Twitter API密钥
- 遵守平台使用条款
- 注意API调用限制
