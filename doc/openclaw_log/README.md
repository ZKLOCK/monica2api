## 使用规范

### 1. 文件命名规范
- **日志文件**：`YYYY-MM-DD_主题描述.md` (如：`2026-03-11_monica_proxy_fix_experience.md`)
- **记忆文件**：`YYYY-MM-DD.md` (如：`2026-03-11.md`)
- **脚本文件**：`功能描述.sh` (如：`test_monica_integration.sh`)

### 2. 文件内容规范
- **日志文件**：记录问题、分析、解决方案、经验教训
- **记忆文件**：记录每日工作重点、决策过程、思考记录
- **脚本文件**：包含清晰的注释和使用说明

### 3. 维护规范
1. **每日更新**：当天工作结束后更新记忆文件
2. **问题记录**：遇到问题时及时记录日志
3. **定期整理**：每月初整理上个月的日志文件
4. **脚本维护**：更新脚本时同步更新README

## 快速导航

### 查找特定日期的日志
```bash
# 查找2026年3月11日的日志
ls logs/2026-03-11_*.md

# 查找Monica相关的日志
ls logs/*monica*.md
```

### 查看工作记忆
```bash
# 查看今天的工作记忆
cat memory/$(date +%Y-%m-%d).md

# 查看昨天的工作记忆
cat memory/$(date -v-1d +%Y-%m-%d).md
```

### 运行测试脚本
```bash
# 运行Monica集成测试
./scripts/test_monica_integration.sh

# 运行验收测试
./scripts/验收测试_v2.sh
```
