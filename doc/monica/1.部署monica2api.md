### 部署 `monica2api` 项目

#### 1. 环境准备
确保您的系统上安装以下软件：
- **Go 1.18+**：用于构建后端。
- **Node.js 16+**：用于构建前端。
- **npm** 或 **yarn**：用于管理 JavaScript 依赖。

#### 2. 安装 Go
如果您还没有安装 Go，可以从 [Go 官方网站](https://golang.org/dl/) 下载并安装。

#### 3. 安装 Node.js
您可以从 [Node.js 官方网站](https://nodejs.org/) 下载并安装 Node.js。

#### 4. 克隆项目
使用以下命令从 GitHub 克隆项目：
```bash
git clone https://github.com/SimonUTD/monica2api.git
cd monica2api
```

#### 5. 安装 Wails
确保您已经安装 Wails。如果尚未安装，可以使用以下命令安装：
```bash
go install github.com/wailsapp/wails/v2/cmd/wails@latest
```
请确保将 Go 的 `bin` 目录（通常在 `C:\Users\<YourUsername>\go\bin` 或 `~/go/bin`）添加到系统的 PATH 中，以便可以直接使用 `wails` 命令。

#### 6. 安装前端依赖
在项目目录中，使用 npm 或 yarn 安装前端依赖：
```bash
# 使用 npm
npm install

# 或者使用 yarn
yarn install
```

#### 7. 构建项目
使用 Wails 构建项目：
```bash
wails build
```
这将根据项目的配置构建应用程序。

#### 8. 运行项目
构建完成后，您可以运行项目：
```bash
wails serve
```
这将启动开发服务器，您可以在浏览器中访问应用程序。

### 9. 访问应用
根据项目的配置，您可以在浏览器中访问应用，通常是 `http://localhost:3000` 或其他指定端口。

### 总结
确保按照上述步骤逐一执行，并根据需要调整命令。如果在某个步骤中遇到问题，请提供具体的错误信息，我将帮助您解决！
