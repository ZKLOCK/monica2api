## 先回答你的核心问题

### ❓ conversation_id 能自定义吗？
**不能自定义** —— 这个 ID 是 Monica 服务端生成并返回的，你只能**拿来用**，不能自己造一个传过去。

### ❓ 能给窗口加标题吗？
目前 Monica OpenAPI **没有提供重命名对话的接口**，标题通常是由第一条消息内容自动生成的。

## ✅ 按天生成一个窗口 — 完全可以实现！

思路就是：**本地存一个 `date → conversation_id` 的映射文件**，每天第一次调用时新建对话，当天后续调用都复用。

````artifact
id: daily-conversation-manager
name: 按天复用 conversation_id 管理器
type: code.python
content: |-
  import requests
  import json
  import os
  from datetime import datetime

  # ============================================================
  # 配置区
  # ============================================================
  API_KEY = "your_monica_api_key"
  BASE_URL = "https://openapi.monica.im/v1"

  # 本地存储文件：记录每天的 conversation_id
  CONV_STORE_FILE = "conversation_store.json"

  # ============================================================
  # 本地存储：读 / 写
  # ============================================================
  def load_store() -> dict:
      """读取本地存储的 conversation_id 映射"""
      if os.path.exists(CONV_STORE_FILE):
          with open(CONV_STORE_FILE, "r") as f:
              return json.load(f)
      return {}

  def save_store(store: dict):
      """保存 conversation_id 映射到本地"""
      with open(CONV_STORE_FILE, "w") as f:
          json.dump(store, f, ensure_ascii=False, indent=2)

  # ============================================================
  # 获取今天的 conversation_id
  # ============================================================
  def get_today_conv_id() -> str | None:
      """获取今天已有的 conversation_id，没有则返回 None"""
      today = datetime.now().strftime("%Y-%m-%d")
      store = load_store()
      return store.get(today)

  def save_today_conv_id(conv_id: str):
      """保存今天的 conversation_id"""
      today = datetime.now().strftime("%Y-%m-%d")
      store = load_store()
      store[today] = conv_id
      save_store(store)
      print(f"✅ 已保存今日对话 ID [{today}]: {conv_id}")

  # ============================================================
  # 发送消息（核心函数）
  # ============================================================
  def chat(message: str) -> str:
      """
      发送消息，自动管理 conversation_id：
      - 今天已有对话 → 复用
      - 今天没有对话 → 新建，并保存
      """
      headers = {
          "Authorization": f"Bearer {API_KEY}",
          "Content-Type": "application/json"
      }

      conv_id = get_today_conv_id()

      payload = {
          "model": "claude-sonnet-4-6",
          "messages": [{"role": "user", "content": message}],
          "stream": False
      }

      # 今天已有对话，复用
      if conv_id:
          payload["conversation_id"] = conv_id
          print(f"♻️  复用今日对话: {conv_id}")
      else:
          print("🆕 今天还没有对话，新建中...")

      response = requests.post(
          f"{BASE_URL}/chat/completions",
          headers=headers,
          json=payload
      )
      result = response.json()

      # 如果是新建对话，保存返回的 conversation_id
      if not conv_id:
          new_conv_id = (
              result.get("conversation_id") or
              result.get("id") or
              result.get("data", {}).get("conversation_id")
          )
          if new_conv_id:
              save_today_conv_id(new_conv_id)

      # 提取回复文本
      reply = result["choices"][0]["message"]["content"]
      return reply

  # ============================================================
  # 使用示例
  # ============================================================
  if __name__ == "__main__":
      # 当天多次调用，自动复用同一个对话窗口
      print(chat("测试消息 1：今天天气怎么样？"))
      print("---")
      print(chat("测试消息 2：帮我写一个冒泡排序"))
      print("---")
      print(chat("测试消息 3：继续优化上面的代码"))
````

## 整体逻辑流程

```
每次调用 chat()
    ↓
读取本地文件，查今天有没有 conv_id
    ↓
有 → 带上 conv_id 发请求（复用今天的窗口）
没有 → 不带 conv_id 发请求（新建）→ 拿到返回的 conv_id → 存本地
```
